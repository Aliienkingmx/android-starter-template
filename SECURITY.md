# Política de seguridad / Security Policy

## Versiones soportadas / Supported versions

La última versión publicada en Releases es la única soportada.

## Reportar una vulnerabilidad / Reporting a vulnerability

**No abras un issue público.** Envía un correo a `luisztr70@gmail.com`
describiendo el problema con detalle. Recibirás una respuesta en un plazo
razonable y coordinaremos el fix y el aviso.

_No uses issues públicos para reportar vulnerabilidades._
